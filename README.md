# CSS Colored Boxes

A frontend web development project built with **HTML5 and CSS3** to explore CSS color formats, element dimensions, box styling, and layout techniques.

The project features five colored boxes, each demonstrating a different CSS color representation. It provides practical experience applying hexadecimal, RGB, predefined color names, and HSL values while organizing elements within a structured layout.

## Project Overview

CSS Colored Boxes is a hands-on learning project designed to strengthen foundational CSS skills. It demonstrates how different color formats can be applied to HTML elements and how dimensions, spacing, and layout properties contribute to a clear, organized design.

## Features

- **Five Distinct Color Boxes:** Uses individual CSS classes to apply different styles to each box.
- **Multiple CSS Color Formats:** Demonstrates hexadecimal, RGB, predefined color names, and HSL.
- **Structured Layout:** Organizes the boxes within a dedicated `.color-grid` container.
- **Element Sizing:** Uses width, height, and minimum dimensions to control box appearance.
- **Individual Styling:** Applies separate styles through the `.color1` to `.color5` classes.
- **Organized Code:** Separates HTML structure from CSS presentation.

## Getting Started

Follow these steps to run the project on your computer.

### Prerequisites

- Git installed on your computer.
- A modern web browser.
- A code editor, such as Visual Studio Code.

### Installation and Setup

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with the actual URL of your GitHub repository.

**2. Navigate to the project directory**

```bash
cd colored-boxes
```

**3. Open the project**

Open the project folder in your preferred code editor.

**4. Run the application**

Open `index.html` in your web browser to view the colored boxes. No build tools, package installations, or backend server are required.
